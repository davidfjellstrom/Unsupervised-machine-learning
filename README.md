# Unsupervised Machine Learning

Grupprojekt i kursen Unsupervised Machine Learning.

## Projektbeskrivning

Projektet går ut på att välja ett dataset, rengöra data, utföra EDA och applicera minst en unsupervised ML-teknik. Resultatet presenteras som en databerättelse.

## Steg

1. Välj dataset
2. Datarening
3. EDA — statistik och visualiseringar
4. Unsupervised ML (t.ex. k-means klustring)
5. Tolkning och presentation (~15 min)

## Tekniker

- Python
- pandas, scikit-learn, matplotlib/seaborn
